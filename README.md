# blade-app-practice

## 概要
COACHTECH 教材 Tutorial 9-2「Bladeテンプレート ハンズオン演習」で作成した成果物です。<br>
商品一覧ページを作成しました。

## 使用技術
- PHP 8.5.12
- Laravel 10.50.3
- Blade テンプレート

## 学んだこと
- Viewファイルを変更せず、フロントエンド側が要求するデータをコントローラーで準備する実装方法
- 提供されたBladeファイルを読み解き、必要な変数やデータ構造を把握する方法
- Bladeの@forelse、@emptyを使用したデータの繰り返し表示と、データが存在しない場合の表示処理

## 動作確認
GitHubから本プロジェクトを取得し、Laravel Sailを使用して起動することで動作確認できます。<br>
ブラウザで商品一覧ページが正常に表示されることを確認してください。<br>
※ 実行にはDocker環境および初期設定が必要です。<br>
